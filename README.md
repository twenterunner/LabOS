# LabOS Prototype Build POC — REV 1.0.120

Static HTML/CSS/JavaScript proof-of-concept for GitHub Pages. Upload **all files and the `assets` folder from the root of this ZIP to the repository root**.

REV 1.0.120 fixes the REV 1.0.119 startup regression while retaining the new full-width Green/Yellow day-level replanning interaction in both the main Planning tab and each build's Schedule tab. Normal task taps open Planned Task; canonical tests also provide single-test sister-lab routing.

The browser data schema remains 35. Existing LabOS IndexedDB data is therefore retained when updating from the previous revision.
