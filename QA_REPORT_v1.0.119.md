# LabOS REV 1.0.119 — focused planning regression report

## Result
REV 1.0.119 qualifies the new in-swimlane manual-planning interaction against the canonical planning engine and the existing multi-lab model.

## In-lane planning qualification
- The selected task is evaluated by calendar day, not AM/PM or minute slots.
- A 91-day scan produced validated alternatives across the displayed width.
- Green candidates required no readiness insertion and no movement of any other build.
- Yellow candidates contained governed readiness insertions (calibration / maintenance / training) and no movement of another build.
- The proposed booking day exactly matched the selected calendar-day constraint; downstream work was generated by the canonical solver.
- Candidates that would move another programme are intentionally excluded from Green/Yellow and remain an Escalation/Tier-3 decision.

## Fault injection
All matching equipment was removed for an equipment-requiring booking. The planner returned `ZERO_EQUIPMENT_CAPABILITY` with a concrete structural diagnosis instead of an empty date list.

## Sister-lab regression
A single test was transferred to a sister lab and another task in that build was manually replanned. The transferred test remained at the sister lab with `remoteExecution=true`, proving in-build replanning does not silently pull a governed remote test back home.

## Packaging
The Rev 118 out-of-scope patch placement was corrected. All Rev 119 runtime files are referenced from `index.html`; IndexedDB schema is unchanged at 35.

## Boundary
Automated Chromium navigation to localhost/file URLs is blocked by administrator policy in the execution environment, so a physical Android browser smoke test is still recommended after deployment.
