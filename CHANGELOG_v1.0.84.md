# LabOS REV 1.0.84 — unified interface system

This release applies one operational visual language across the application.

- Standardised page hierarchy, action hierarchy, navigation, status indicators, cards, tables, forms, workflow controls and dialogs.
- Improved readability using a more restrained surface palette, typographic scale, spacing rhythm and denser—but clearer—data tables.
- Harmonised primary, secondary, next-action and destructive controls throughout the app.
- Strengthened responsive behavior on tablet and mobile without hiding controlled information.
- Retained visible keyboard focus, reduced-motion support and accessible dialog behavior introduced in REV 1.0.83.

No material, planning, workflow, audit, quality or evidence semantics were changed.
