# LabOS REV 1.0.119 — change log

## Manual planning UX
- Replaced the Rev 118 modal-first move flow with direct **full-width in-swimlane Green / Yellow day alternatives**.
- Implemented the same interaction in the Master Planning timeline and every build-specific universal timeline instance.
- Green/Yellow alternatives are generated by the canonical `PlanningEngineV1096.manualPlan` path and reject any candidate that would silently move another programme.
- Yellow acceptance shows the exact governed readiness actions before committing.
- Drag/drop from the desktop move grip and click/tap on a highlighted day use the same validated proposal transaction.
- Timeline pan/zoom while move mode is active triggers a rescan of the newly visible width.
- If no option is visible, the planner searches beyond the chart, expands to the first feasible solution, and then rescans that displayed width.

## Stability correction
- Corrected a Rev 118 packaging/scope defect where the day-planning/mobile patch had been appended after the main application IIFE. Rev 119 places those revisions back inside the application scope.

## Preserved behavior
- Normal task tap opens Planned Task rather than accidentally starting a move.
- Single-test sister-lab routing remains available from the Planned Task dialog.
- Downstream tasks are regenerated by the same canonical planner after a selected manual day.
- IndexedDB schema remains 35.
