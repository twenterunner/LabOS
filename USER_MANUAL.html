How engineering requests a prototype
  1. Open Prototype Requests and choose New prototype request.
  2. Complete the six guided wizard steps.
  3. Create the controlled draft, review it, then submit when required data is complete.
  4. Track Requested Date, Current Forecast, Readiness, Risk, Owner and Next Action in the request workspace.
How lab triages and plans a request
  1. Open the request workspace and review objective/configuration/date.
  2. Use Action Centre items to resolve clarification, material, process, quality or approval needs.
  3. Use AUTO-PLAN to search valid equipment and qualified available staff.
  4. Review the forecast and readiness gate.
How to select or develop a process
  1. Open Visual build flow.
  2. Insert a released standard process where its released envelope fits.
  3. Choose Modified or New when fit is not adequate.
  4. Complete development plan, trials, parameter definition, risk, measurement/capability, Control Plan, work instruction, approval and release.
How to create/review a Control Plan
  1. Open Control Plan from the request.
  2. Confirm each special characteristic has a suitable control, gauge/method, sampling, evidence and reaction plan.
  3. Use independent approval where separation of duties is configured.
  4. Create a new revision rather than silently modifying approved content.
How to perform Build Readiness Review
  1. Open the Control Plan tab and Build Readiness Review.
  2. Review product, BOM, material, processes, risk, Control Plan, work instructions, equipment, calibration, competence, special characteristics, measurements and configured safety/customer gates.
  3. For each blocker, follow the displayed What / Why / Who / Action / Evidence / Then guidance.
  4. Use controlled override only with authorised role, reason and risk/impact.
How a technician executes a build
  1. Switch to Prototype Technician.
  2. Open Execution for the active request.
  3. Select serial and valid equipment, enter actual parameter/evidence, and complete the controlled step.
  4. Mandatory evidence is required and the serial process history is updated.
How to record characterisation
  1. Open Characterisation.
  2. Use manual or CSV entry where available.
  3. Retain raw values with unit, limits, serial, method, equipment/calibration, operator and timestamp.
  4. Out-of-limit results remain visible and can drive a quality hold.
How to manage deviation / rework
  1. Open Quality / deviations.
  2. Contain the affected build/serial and investigate.
  3. Choose an authorised disposition.
  4. For rework, return through the controlled route and reinspection; close only after mandatory verification.
How to sign off, release and deliver
  1. Review approvals, serial counts, configuration, characterisation and deviations.
  2. Do not release with unresolved release holds.
  3. Record formal sign-offs required by configured customer/product-safety rules.
  4. Prepare delivery/handover for released serials and acknowledge receipt.
How to find serial-number history
  1. Use global search or Serial History.
  2. Open the serial.
  3. Review request, configuration, material lots, process revisions, measurements, deviations/rework and delivery history.
How to generate a Prototype Build Report
  1. Open Reports or the request Documents tab.
  2. Generate the controlled report view.
  3. Draft reports are marked AUTO-GENERATED · NOT APPROVED.
  4. Use browser print/save-PDF to create a portable copy.

Compliance scope

This proof-of-concept supports organisation-configurable IATF 16949-aligned controls. It does not itself certify compliance or replace controlled procedures, customer-specific requirements, authoritative e-signatures, validation, training, record retention or corporate system governance.
